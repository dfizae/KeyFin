# AI 코칭 검증 결과

**현재 유지할 예측기는 팀 FDT입니다.** 2026-09-10에 사전학습 모델, 추가 학습, 단순 평균을 포함한 11개 후보를 같은 SEED 미래 소비 구간에서 비교했지만 FDT보다 오차가 낮은 후보가 없었습니다. 이는 ‘최고의 금융 AI’를 입증한 결과가 아니라, 이번 조건에서 모델 교체 근거를 얻지 못했다는 뜻입니다.

## 무엇을 따로 검증했는가

| 검증 | 정답·비교 기준 | 해석 범위 |
| --- | --- | --- |
| 금융 처리 회귀시험 | 직접 지정한 거래·잔액·중복·취소 계약 | 구현이 명시한 계약을 지키는가 |
| 합성 질문·코칭 HTTP 시험 | 사전 지정 경로와 숫자·출처 검사 | 분류·설명·오류 복구가 동작하는가 |
| 미래 소비 예측 | 기준일 이후 SEED 원장 소비 합계 | 해당 SEED의 관측된 미래를 얼마나 맞혔는가 |
| 독립 사람 승인 원장·실제 고객 미래 | 아직 확보하지 않음 | 현재 결과로 주장할 수 없음 |

원장 정답은 예측 모델로 생성하지 않았습니다. 다만 SEED 자체는 합성 데이터이며, 평가 어댑터는 제품의 거래 분류·기간 규칙 일부를 공유합니다. 따라서 독립적인 사람의 금융 원장 감사나 실사용자 검증이라고 부르지 않습니다.

## 소비 예측 비교: R7

원장 4명 × 봉투 7종에서 7월 개발 336개, 8월 평가 336개 사례를 구성했습니다. 기준일은 1·8·15·22일이며 미래 7일·14일·30일·월말 가운데 미래 관측이 완성된 사례만 씁니다. 학습은 다른 사용자 3명의 6월 30일까지 데이터, 선택·구간 보정은 그 3명의 7월입니다. 제외 사용자의 8월을 평가하는 4개 fold를 합칩니다.

Chronos-2 full fine-tuning을 두 조건 × 네 fold, 총 8회 실제 실행했습니다. 64 steps / 1e-6 및 128 steps / 3e-6, batch 32, seed 712입니다. 기본 모델과 기존 합성 학습 체크포인트도 따로 비교했습니다. 상세 입력 분리·추론·후처리·재현 절차는 [프로토콜](../benchmarks/forecast/README.md)에 있습니다.

### 숫자의 의미

`y`는 해당 사용자·봉투·기간의 실제 소비, `p`는 점 예측입니다.

| 지표 | 계산 | 읽는 방법 |
| --- | --- | --- |
| WAPE | `sum(abs(p-y)) / sum(y)` | 실제 소비 합계 대비 절대오차 합계입니다. 61.42%를 ‘정확도 38.58%’로 바꾸지 않습니다. |
| MAE | `mean(abs(p-y))` | 한 봉투·기간 사례당 평균 오차입니다. 한 사람의 전체 월 소비 오차가 아닙니다. |
| 평균 편향 | `mean(p-y)` | 음수는 과소 예측, 양수는 과대 예측입니다. |
| 80% 구간 포함률 | `lower <= y <= upper`인 사례 비율 | 목표 80% 부근인지 확인합니다. 무조건 높을수록 좋은 지표가 아닙니다. |
| 평균 구간 폭 | `mean(upper-lower)` | 포함률을 높이기 위해 범위가 지나치게 넓어졌는지 봅니다. |
| 구간 점수 IS | `width + 10*max(lower-y,0) + 10*max(y-upper,0)` | 넓은 구간과 구간 밖 오차에 모두 비용을 줍니다. |
| WIS | `mean((0.5*abs(p-y)+0.1*IS)/1.5)` | 점 오차와 80% 구간 점수의 가중 평균입니다. |
| 정규화 WIS | `WIS / mean(y)` | 동일 평가 집합 안에서 비교할 비율이며 낮을수록 좋습니다. |

WAPE의 실제 소비 분모 합계는 50,344,950원입니다. 서로 겹치는 기간이 있어 **중복 없는 거래 총액이나 서비스 거래 규모가 아닙니다**. 실제 합계가 0인 집단의 WAPE는 정의하지 않고 `null`로 표시합니다.

### 구간 보정은 채택하지 않음

FDT의 원래 구간 포함률은 252/336 = 75.00%, 보정 후는 291/336 = 86.61%였습니다. 그러나 평균 폭이 149,583원에서 314,505원으로 넓어졌고 정규화 WIS도 **0.5137 → 0.5576으로 악화**했습니다. 점 예측 오차는 변하지 않습니다. 포함률 하나만 보고 성능이 개선됐다고 주장하거나 이 보정을 제품에 적용하지 않았습니다.

FDT의 기간별 WAPE는 7일 69.88%(112개), 14일 54.83%(84개), 30일 53.42%(28개), 월말 64.48%(112개)입니다. 장기간 사례가 훨씬 적고 중복이 있어 기간 간 우열을 일반화할 수 없습니다.

## 코칭 연결과 기간 수정: 기존 검증

R5에서는 약 26,000글자 근거가 추론 서버의 8,192토큰 한도를 넘는 문제를 SEED 동등 구조로 재현했습니다. 문제가 제보된 요청 원문 전체는 확보하지 못했습니다. 현재는 작업별 근거 선택과 동일 토크나이저의 요청 선검사를 사용합니다. 실제 HTTP 24개 합성 시나리오, 41회 생성에서 설명 채택 26/27, 판정 5/5, 경로 9/9를 관측했습니다. 이 숫자는 해당 호출에서의 계약 통과이며 소비 예측 정확도나 전문가 답변 품질 점수가 아닙니다.

R6에서는 기준일 다음 날부터 종료일까지로 기간 계산·표시를 맞추고 월말·목표일을 분리했습니다. 실제 추론을 사용한 기간 사례 7개, 총 21회 호출에서 최종 설명 7/7이 채택됐습니다. 동일 사례 수정 전 설명 채택은 1/7이었습니다. 이는 날짜 계약을 포함한 설명 처리 개선으로, 미래 금액이 더 정확해졌다는 근거는 아닙니다.

이전 R5 소비 예측 결과인 WAPE 55.20%(단순 기준 55.58%), 원래 구간 포함률 29/56 = 51.79%는 다른 기간·집계 단위의 56개 봉투 사례입니다. R7의 336개 평가와 분모가 달라 시계열 개선 추세처럼 나란히 비교하지 않습니다.

## 디렉터리 정리 후 재검증: 2026-09-11

서비스 실행 코드는 `src/`와 `scripts/`, 성능 실험 실행기는 `benchmarks/`, 검증 코드는 `tests/`, 실행 부산물은 Git에서 제외하는 `artifacts/`로 분리했습니다. 서비스 원본 31개 모듈과 FDT 21개 파일은 기존 실행본과 바이트가 같습니다. 추론 로더는 과거 실험 디렉터리 참조를 없애고 개인 모델 등록 파일을 읽도록 변경했습니다.

전체 테스트 **389개**, Ruff 검사, 서비스 소스 범위의 엄격 타입 검사가 통과했습니다. 빌드한 wheel을 별도 환경에 설치하고 실제 추론 워커와 연결해 **24개 시나리오·206개 HTTP 요청·612개 계약 검사**를 확인했습니다. 생성 41/41, 토큰 선검사 41/41은 HTTP 200이었고 실제 입력 토큰 수 불일치는 0건입니다.

이번 실행의 LLM 설명 채택은 **20/27**, 판정은 5/5, 경로 출력 채택은 9/9입니다. 설명 7개는 숫자 출력 4개·근거 밖 주장 1개·지원하지 않는 형식 2개로 거절되어 템플릿을 반환했습니다. 경로 정답을 별도로 지정한 사례는 4개이며 4/4가 일치했습니다. 채택 9/9를 정답 라벨 9개에 대한 정확도라고 해석하지 않습니다. 기준일이 이전 실행과 달라 R5의 26/27과 통제된 개선·퇴행 비교를 할 수 없고, 설명 채택률의 추가 개선 여지는 남습니다.

이 41회 순차 생성 요청의 모델 게이트웨이 응답 시간 중앙값은 2.58초, 95백분위수는 4.94초입니다. 토큰 선검사·FDT 계산을 모두 합친 사용자 응답 지연이나 동시 부하 시험 결과가 아닙니다. 원시 보고서 SHA-256은 `eb18d5085b55743e54174981c5815ac08b11c8c03c1a5ffc6f58b4ae9599219a`이며 별도 보관합니다. 기존 운영 endpoint를 전환한 배포와 새 패키지의 격리 설치·실행 검증은 구분합니다.

예측 실험도 새 경로에서 입력과 점수를 재생했습니다. 입력·정답·기준선은 원본과 같고 11개 후보 결과도 같았습니다. 선택 정책 요약에서 보정 후 값을 보정 전 필드에도 넣던 표기만 수정했습니다. 제품·평가기 함수를 호출하지 않는 별도 산술 검사로 8개 학습 기록의 입력 분리·가중치 변경 기록과 220개 지표 값을 대조했습니다. 이는 자체 재검증이며 독립 인간 감사는 아닙니다.

## 재현과 남은 검증

R7 원시 수집 묶음 SHA-256은 `b2b2b3cb48f3a7795e736a3c0bce455aa9a858d168cc2b5fc90146cb3a9c6716`입니다. 원시 예측·학습 기록·로그는 별도 실험 보관소에 유지하고 이 저장소에는 현재 실행기와 본 보고서를 둡니다. 원장과 과거 합성 학습 체크포인트가 있어야 같은 비교 전체를 재실행할 수 있습니다.

4명뿐인 기존 SEED를 이전 실험에서도 열람했으므로 새 비공개 최종 검증셋이 아닙니다. 거래일과 실제 수신 시점의 차이, 다양한 고객군, 90일 미래, 장기 드리프트와 전문가 코칭 평가는 미검증입니다. 회귀시험·자체 재계산은 독립 감사 승인을 대신하지 않습니다. 다음 단계는 별도로 정답을 승인한 금융 사례와 동의받은 실제 거래의 시간 순서 평가이며, 이번 실험 결과를 근거로 모델을 바꾸지 않습니다.
